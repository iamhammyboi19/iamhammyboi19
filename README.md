### 👋 Hi, I'm Ahmed - a Systems-Focused Software Engineer

I hold a BSc in Computer Engineering from Near East University. My primary focus is modern C++ systems programming, with strong interest in how software interacts with the operating system, CPU architecture, and memory hierarchy.

I build performance-oriented software and networking systems. One of my core projects is a custom socket-based file transfer system written in C++, built using epoll (Linux) and kqueue (macOS) with an event-driven architecture, binary protocol, and multithreaded I/O model.

My engineering interests include:

* High-performance networking
* Event-driven system design
* Concurrency and lock-free programming
* Cache-aware data structures
* OS-level systems and runtime behavior

While my primary focus is systems programming, I also have experience building backend services and full-stack applications using Node.js, PostgreSQL, MongoDB, and React.

Currently I am strengthening my data structures and algorithmic problem solving while continuing to build low-level systems projects such as parsers and networking tools.
